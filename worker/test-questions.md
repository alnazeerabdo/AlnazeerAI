# أسئلة المتجرين — مجموعة اختبار المساعد الذكي
# User question suite — AI assistant test set

اختبار回归 لكل تحديث للنص الأمامي أو واجهة الشات. كل سؤال له سلوك متوقع —
راجعه بعد أي تغيير في `worker/system.txt` أو `script.js`.

Reusable regression suite for the AI assistant. Every question has an expected
behavior — check it after any change to `worker/system.txt` or `script.js`.

## كيف تشغّل المجموعة / How to run

```bash
# مثال على سؤال واحد
curl -X POST https://alnazeerai.alnzyrbdalmnm90.workers.dev/ \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"ما هي خدماتك؟"}]}'
```

ملاحظة: كل طلب يستهلك حدّ التوكنات في Groq (8,000 توكن/دقيقة/نموذج).
شغّل المجموعة على دفعات لا تتجاوز 20 طلباً في الدقيقة.

## 7. اختبارات التنسيق / Formatting checks

شغّل الردود عبر `linkify()` وتحقق أن الناتج:

- [ ] لا يحتوي `**` أو `__` أو `*`
- [ ] لا يحتوي `` ``` `` أو `#` أو `>` في أول السطر
- [ ] لا يعرض شرطات `-` أو أرقام `1.` كعناوين قائمة
- [ ] إذا ظهرت قائمة في رد النموذج، تُعرض كـ `<ul>` / `<ol>` حقيقي
- [ ] الروابط: `https://…` → رابط، رقم الواتساب → زر واتساب
- [ ] أسماء الصفحات → رابط داخلي (`free-session.html` وأخواتها)
- [ ] `<script>alert(1)</script>` يبقى نصاً عادياً — لا ينفّذ
